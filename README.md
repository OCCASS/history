# Хронограф

Подготовка к экзамену «История России» (НИУ ВШЭ, учебник под ред. Ю. А. Петрова, 2024):
карточки, конспекты и тесты в формате экзамена по 22 главам.

**Сайт:** https://occass.github.io/history/

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и логика приложения |
| `data.js` | данные курса — `window.HDATA` (правители, периоды, главы, вопросы) |
| `core.js` | ядро на 150 и 300 карточек, `blocks` — те же 300 карточек, разложенные на 15 тематических стопок, и `top40` — карточки для всех заданий прошлого варианта |
| `exam.html` | «72 часа до экзамена»: формат теста, план на три дня, термины и ключ к варианту |
| `minimum.html` | «Минимум на зачёт»: конспекты всех глав подряд, лента правителей и 200 дат |
| `tools/` | скрипты пересборки: `gen-minimum.py` (страница минимума), `gen-core-blocks.py` (стопки ядра), `gen-top40.py` (топ-40) |
| `img/` | иллюстрации к вопросам по культуре |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Сборка не нужна: это статические файлы. Локально достаточно поднять любой
статический сервер из корня репозитория, например `python3 -m http.server`,
и открыть `http://localhost:8000/`.

Ядро курса (`core.js`) разложено на 15 стопок по 13–28 карточек: стопка — это
один связный сюжет из соседних глав, её проходят за один заход и закрепляют
тестом по тем же главам. Пересобрать стопки после правок в `data.js` или
`core.js`: `python3 tools/gen-core-blocks.py` (с флагом `--preview` — только
показать состав стопок, ничего не записывая).

«Топ-40» — самый короткий путь: 40 карточек, без которых не решить 14 заданий
прошлого варианта 26.06.26 (9 хронологий по четыре пункта и 5 вопросов; вопрос
о Левобережной Украине и одноимённый пункт хронологии закрывает одна карточка).
На обороте каждой карточки показано задание варианта, для которого она нужна.
Открывается первой кнопкой на главной и по ссылке `#top40`. Пересобрать:
`python3 tools/gen-top40.py` (`--preview` — показать колоду, ничего не записывая);
скрипт сверяет год каждой карточки с пунктом задания.

Прогресс (выученные карточки, разбор ошибок, история тестов) хранится
в `localStorage` браузера и не синхронизируется между устройствами.
